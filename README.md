# Mini Task Management Application

Study case submission for **Executive Full Stack Developer - WPP Media**.

This repository contains two independent services:

- **`backend/`**: Django REST API for boards and tasks
- **`frontend/`**: Next.js UI that consumes the backend over HTTP

The root README is intentionally short. Each service keeps its own setup, run instructions, and dependency details in its local README.
